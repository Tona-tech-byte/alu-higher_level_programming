# Python - Almost a Circle

This project is part of the ALU Higher Level Programming curriculum.

## Description

The project focuses on Python classes, inheritance, file handling,
serialization, and unit testing.

## Project Structure

- `models/` - Contains the project classes.
- `tests/` - Contains unit tests for the project.
- `README.md` - Project documentation.

## Running Tests

Run all unit tests with:

    python3 -m unittest discover tests

## Requirements

- Python 3
- PEP 8 coding style
- Unit tests using the unittest module
