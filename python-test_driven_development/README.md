# Python - Test Driven Development

This directory contains Python functions and their tests.

## Task 0: Integers Addition

**File:** `0-add_integer.py`

The `add_integer(a, b=98)` function adds two integers.

- Accepts integers or floats.
- Converts floats to integers before addition.
- Uses 98 as the default value of b.
- Raises a TypeError if either argument is invalid.
- Returns an integer.

## Testing

Run the tests using:

`python3 -m doctest -v ./tests/0-add_integer.txt`
