The add_integer function
========================

Import the function:

    >>> add_integer = __import__('0-add_integer').add_integer

Add two integers:

    >>> add_integer(1, 2)

Add a positive and negative integer:

    >>> add_integer(100, -2)
    98

Use the default value of b:

    >>> add_integer(2)
    100

Add floating-point numbers:

    >>> add_integer(100.3, -2)

Convert floats to integers before adding:

    >>> add_integer(1.9, 2.9)
    3
